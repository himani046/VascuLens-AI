# VascuLens AI frontend

React + Vite + React Three Fiber dashboard.

```bash
npm install
npm run dev
```

Start the FastAPI backend separately (see the root README). Set VITE_API_URL=http://127.0.0.1:8000 in .env when needed.

The included heart/vessel scene is schematic and the vessel interior is illustrative, not a CT-derived lesion map.
